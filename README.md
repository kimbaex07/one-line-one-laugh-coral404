# One Line, One Laugh

> My therapist said I should stop acting like a software update — everyone keeps postponing me and I only work after a restart.

Character count: 125

## Why it lands

The line opens like a therapy confession, then swerves into tech: the narrator is not a person with problems, he is a software update. The turn lands because "postponing" and "only work after a restart" are both literal update behaviour and painfully accurate human behaviour at once — everyone has clicked "Remind me later" on a person, and everyone has needed a restart to function.

## How to run

```bash
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes the line to `./out/entry.txt`.
